# mini-projects

**Author:** João Henrique Porfirio Firmiano

🟠 Java

It is a simple interactive narrative game, where the player makes choices by typing numbers, receives a story outcome, and can restart the game as many times as they want.

## Problem

After the basic exercises, I wanted to practice Java control flow and console input in something more fun than isolated examples.

## Solution

I built **The Lost Sword**, a short text adventure: the player picks an option by typing a number, gets one of three endings and can play again. I wrote the game myself, without AI, to practice `Scanner`, `if/else` and `do/while`. **Claude (Anthropic)** was only used later to translate this README.

## Technologies

- Java (JDK 11+)
- `Scanner` for console input
- Claude (Anthropic): README only

## Demo

Console game, with no published demo. Run it in the terminal (see [Repository](#repository)).

## Result

- A playable game with three endings and a replay loop.
- Practice with input handling and loops in a complete program instead of separate snippets.
